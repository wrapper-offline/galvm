# GALVM
GALVM (Good, Awesome and Luxurious Video Maker) is a 1:1 decompilation of all legacy Adobe Flex-based software developed by GoAnimate, Inc. This includes the:
* Anifire Library
* Browser
* Creator
* Player
* Studio
