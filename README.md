# GALVM
GALVM (Good, Awesome and Luxurious Video Maker) is a 1:1 decompilation of all legacy Adobe Flex-based software developed by GoAnimate, Inc. in 2016. This includes the:
* Anifire Library
* Browser
* Creator
* Studio
